## 현재 겹침을 검사하는 역할

접촉 판정은 현재 위치에서 두 형상이 겹치는지 확인하고, 겹쳐 있다면 분리 방향과 깊이를 반환한다. 이동 경로의 충돌 시점은 [Shape Cast](ShapeCast.md)가 계산한다.

접촉 판정은 위치를 직접 변경하지 않는다. 솔버가 반환된 접촉 정보를 받아 정적·동적 바디의 정책에 따라 보정을 적용한다. 같은 형상 판정을 초기 겹침 해소, Discrete 이동 후 보정, Cast의 시작 겹침 검사에서 사용한다.

## 법선과 분리 벡터의 기준

A를 첫 번째 바디, B를 두 번째 바디로 검사할 때 법선 `n`은 A를 B에서 분리하는 방향이다. 외부 접촉에서는 B에서 A를 향하고, 포함된 형상에서는 선택한 출구 방향이 된다.

| 정보 | 의미 |
| --- | --- |
| `SeparationNormal` | A를 분리할 단위 방향 `n` |
| `PenetrationDepth` | 해당 방향으로 겹침을 해소하는 거리 `p` |
| `SeparationMtv` | 분리 방향과 거리를 합친 벡터 `n × p` |

$$
\mathrm{MTV}=n\,p
$$

A에 MTV 전체를 더하면 B를 고정한 채 A를 분리한다. 동적 쌍에서 MTV를 나누는 비율은 접촉 판정이 아니라 각 솔버가 결정한다.

## 원과 원

두 중심의 차이를 `q = centerA - centerB`, 반지름 합을 `R = radiusA + radiusB`로 둔다.

$$
L=\lVert q\rVert,\qquad p=R-L,\qquad n=\frac{q}{L}
$$

`L² < R²`일 때 겹침이다. 두 중심이 완전히 같다면 나눗셈으로 법선을 구할 수 없으므로 오른쪽 방향을 사용한다. 정확히 접하기만 하는 `L = R`은 침투 접촉으로 반환하지 않는다.

| 예시 항목 | 값 |
| --- | --- |
| A 중심 / 반지름 | `(0, 0)` / `1` |
| B 중심 / 반지름 | `(1.5, 0)` / `1` |
| 중심 거리 / 반지름 합 | `1.5` / `2` |
| 법선 / 침투 깊이 | `(-1, 0)` / `0.5` |
| A의 MTV / 보정 후 중심 | `(-0.5, 0)` / `(-0.5, 0)` |

## 박스와 박스

박스는 축에 정렬된 AABB다. 중심 차이를 `q`, half extents 합을 `h`로 두고 각 축의 겹침을 계산한다.

$$
p_x=h_x-|q_x|,\qquad p_y=h_y-|q_y|
$$

어느 한 축의 겹침이 0 이하이면 침투하지 않는다. 두 축 모두 겹치면 더 작은 겹침 축으로 분리한다. 그 축의 중심 차이 부호로 법선을 정한다. 겹침이 같으면 현재 구현은 Y축을 선택한다.

이 판정은 축 정렬 박스에 대한 축별 투영 겹침 검사다. 회전된 박스를 위한 일반적인 여러 축 SAT는 구현되어 있지 않다.

## 원과 박스: 원의 중심이 밖에 있는 경우

원 중심을 박스의 min/max 범위로 clamp하여 박스 위의 가장 가까운 점 `Q`를 구한다. 원 중심을 `C`, 반지름을 `r`로 두면 다음과 같다.

$$
q=C-Q,\qquad L=\lVert q\rVert,\qquad p=r-L,\qquad n=\frac{q}{L}
$$

`L² < r²`이면 겹침이다. 면 가까이에서는 축 방향 법선이 나오고, 모서리 가까이에서는 모서리에서 원 중심을 향하는 대각선 법선이 나온다.

| 예시 항목 | 값 |
| --- | --- |
| 박스 중심 / half extents | `(0, 0)` / `(1, 1)` |
| 원 중심 / 반지름 | `(1.2, 1.2)` / `0.5` |
| 박스의 최근접점 | `(1, 1)` |
| 최근접점까지 거리 | `√0.08 ≈ 0.282843` |
| 법선 | `(1/√2, 1/√2)` |
| 침투 깊이 | `0.5 - √0.08 ≈ 0.217157` |
| MTV | `(0.153553, 0.153553)` |
| 보정 후 원 중심 | `(1.353553, 1.353553)` |

보정은 원래 이동 방향을 그대로 되돌리는 방식이 아니다. 위 모서리 접촉은 X로만 이동해 발생했더라도 MTV의 Y성분이 추가될 수 있다. [Discrete 예시](Discrete.md)에서 최종 이동량까지 연결한다.

## 원과 박스: 원의 중심이 안에 있는 경우

중심이 박스 안에 있으면 clamp 결과가 중심과 같아 일반적인 최근접점 방식으로 법선을 구할 수 없다. 대신 왼쪽·오른쪽·아래·위 면까지의 거리를 비교하고 가장 가까운 면으로 원을 꺼낸다.

$$
p=r+\text{가장 가까운 면까지의 거리}
$$

중심이 면을 넘는 것만으로는 원 전체가 분리되지 않으므로 반지름도 더한다. 예를 들어 위 박스 안의 중심 `(0.8, 0)`, 반지름 `0.5`인 원은 오른쪽 면까지 `0.2`이고, MTV는 `(0.7, 0)`이다. 보정 후 중심은 `(1.5, 0)`이 된다.

현재 구현은 중심이 경계 위에 있어도 내부 분기로 처리한다. 같은 거리의 면이 여러 개면 먼저 선택한 면을 유지한다.

## 박스와 원의 순서가 바뀌는 경우

원과 박스 판정을 재사용한 뒤 법선의 부호를 반전한다. 이를 통해 첫 번째 바디가 박스여도 반환되는 MTV가 그 박스를 분리하는 방향이 되도록 맞춘다. 침투 깊이는 그대로 사용한다.
