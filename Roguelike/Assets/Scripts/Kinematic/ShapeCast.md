## 역할과 처리 범위

Cast는 형상을 지정한 변위만큼 이동시켰을 때 처음 접촉하는 바디와 위치를 계산하는 조회다. 바디를 실제로 이동시키지 않는다. `distance`라는 인자는 길이 하나가 아니라 방향과 거리를 함께 가진 `Vector2` 변위다.

| 계층 | 책임 |
| --- | --- |
| `Kinematics` | 게임 로직에 `CircleCast`, `BoxCast`, `ShapeCast` 제공 |
| `KinematicCast` | 후보 조회와 가장 가까운 결과 선택 |
| `KinematicShapeCast` | 한 형상 쌍의 이동 경로 교차 계산 |

공개 Cast는 정적 바디와 동적 바디를 모두 검사한다. 조회 시점의 대상 위치를 고정하여 검사하며, 대상의 아직 적용되지 않은 이동 요청은 고려하지 않는다. 동적 쌍의 상대 이동은 [Sweep 솔버](Sweep.md)가 별도로 구성한다.

## 후보 조회와 최초 결과 선택

| 순서 | 처리 |
| --- | --- |
| 1 | 이동 형상의 시작 AABB와 끝 AABB를 포함하는 Swept Bounds 생성 |
| 2 | QuadTree에서 경로 AABB와 겹치는 정적 바디 조회 |
| 3 | 동적 목록에서 경로 AABB와 Bounds가 겹치는 바디 선택 |
| 4 | 제외할 바디를 건너뛰고 형상별 Cast 수행 |
| 5 | 가장 작은 이동 비율의 결과 반환 |

AABB 조회는 검사 후보를 줄이는 Broad Phase다. 실제로 닿는지 확인하는 Narrow Phase는 형상별 Cast가 담당한다. `ShapeCast(body, ...)`는 요청 바디 자신을 제외하며, 원·박스 Cast도 `ignoredBody`를 지정할 수 있다.

결과는 하나만 반환한다. 같은 이동 비율의 결과는 이미 선택한 결과를 유지하므로 후보 순서가 동률 선택에 영향을 준다. Sweep은 같은 시점의 접촉들을 모아 처리하는 별도의 선택 과정을 사용한다.

## 형상을 점의 이동으로 바꾸는 방식

움직이는 형상의 크기를 대상 형상에 합쳐 확장하고, 움직이는 형상의 중심을 점으로 검사한다. 두 형상의 Minkowski 확장을 이용하여 형상끼리의 이동 검사를 점과 확장 형상의 교차 검사로 바꾸는 방식이다.

대상 중심을 원점으로 옮긴 상대 시작점을 `o`, 변위를 `d`라고 하면 점의 경로는 다음과 같다.

$$
P(t)=o+t\,d,\qquad 0\leq t\leq 1
$$

`t`는 초 단위 시간이 아니라 이번 변위에서 진행한 비율이다.

| 이동 형상 / 대상 형상 | 점 Cast에 사용할 확장 형상 |
| --- | --- |
| 원 / 원 | 두 반지름을 합한 원 |
| 박스 / 박스 | 두 half extents를 더한 AABB |
| 원 / 박스 | 대상 박스의 half extents를 core로 하고 이동 원의 반지름만큼 둥글게 확장 |
| 박스 / 원 | 이동 박스의 half extents를 core로 하고 대상 원의 반지름만큼 둥글게 확장 |

검사 전 이동량이 수치 허용 범위보다 작으면 Cast를 수행하지 않는다. 그다음 현재 형상이 이미 겹치는지 검사한다. 겹친 상태라면 `t = 0`과 분리 법선을 반환하며, 점 교차 계산을 진행하지 않는다. 따라서 Cast를 이동량 0의 겹침 조회 API로 사용하지 않는다.

## 원 교차: 이차방정식

확장 원의 반지름을 `R`로 두고 경로가 원 경계에 닿는 조건을 전개한다.

$$
\lVert o+t\,d\rVert^2=R^2
$$

$$
a=d\cdot d,\qquad b=o\cdot d,\qquad c=o\cdot o-R^2
$$

$$
a t^2+2bt+c=0,\qquad D=b^2-ac,\qquad t=\frac{-b-\sqrt{D}}{a}
$$

판별식 `D`가 음수이면 경로 직선이 원과 만나지 않는다. 작은 해는 진입 시점이며, 그 값이 이번 변위의 범위에 있을 때만 접촉으로 채택한다. 법선은 접촉 시점의 점을 원 중심에서 바깥으로 정규화한 방향이다.

현재 구현은 범위 판정에 `1e-6`의 허용치를 두고 채택한 비율을 `[0, 1]`로 제한한다. `D = 0`인 접선 접촉은 `IsGrazing`으로 표시한다.

| 계산 예시 | 값 |
| --- | --- |
| 이동 원 중심 / 반지름 | `(0, 0)` / `0.5` |
| 대상 원 중심 / 반지름 | `(3, 0)` / `0.5` |
| 요청 변위 | `(4, 0)` |
| 상대 시작점 / 확장 반지름 | `(-3, 0)` / `1` |
| `a`, `b`, `c`, `D` | `16`, `-12`, `8`, `16` |
| 접촉 비율 / 이동 거리 | `0.5` / `2` |
| 접촉 시 이동 원 중심 | `(2, 0)` |
| 법선 / 접촉점 | `(-1, 0)` / `(2.5, 0)` |

## AABB 교차: Slab 방식

각 축에서 점이 박스의 두 경계 사이에 들어와 있는 이동 비율 구간을 구한다. 한 축의 최소·최대 경계를 `min`, `max`라고 하면 다음 두 값을 계산하고 작은 값을 진입, 큰 값을 이탈 시점으로 정리한다.

$$
t_1=\frac{min-o}{d},\qquad t_2=\frac{max-o}{d}
$$

두 축의 구간이 겹쳐야 점이 박스 안에 들어온다.

$$
t_{enter}=\max(t_{enter,x},t_{enter,y}),\qquad
t_{exit}=\min(t_{exit,x},t_{exit,y})
$$

`t_enter > t_exit`이면 두 축의 내부 구간이 겹치지 않는다. 진입 비율이 이번 변위의 범위를 벗어난 경우에도 접촉이 아니다. 마지막으로 진입한 축의 면 법선을 사용하며, 진입 비율이 같으면 X축 법선을 선택한다.

어느 축의 이동량이 거의 0이면 그 축으로는 경계를 통과할 수 없다. 시작점이 그 축의 범위 안에 있으면 구간을 제한하지 않고, 밖에 있으면 검사에서 탈락시킨다.

| 계산 예시 | 값 |
| --- | --- |
| 이동 박스 중심 / half extents | `(0, 0)` / `(0.5, 0.5)` |
| 대상 박스 중심 / half extents | `(3, 0)` / `(1, 1)` |
| 요청 변위 / 확장 half extents | `(4, 0)` / `(1.5, 1.5)` |
| 상대 X 진입 / 이탈 | `0.375` / `1.125` |
| 접촉 시 중심 / 접촉 비율 | `(1.5, 0)` / `0.375` |
| 법선 / 접촉점 | `(-1, 0)` / `(2, 0)` |

## Rounded Box: 면과 4개의 원호

원과 박스의 확장은 모서리가 둥근 박스가 된다. 단순히 X와 Y에 반지름을 더한 큰 AABB로만 검사하면 실제 둥근 모서리보다 일찍 부딪힌 것으로 판정할 수 있다.

현재 구현은 평평한 면과 모서리 원호를 다음 방식으로 검사한다.

| 검사 영역 | 계산과 채택 조건 |
| --- | --- |
| X 방향으로 확장한 박스 | Slab 검사 후 X축 법선인 좌·우 바깥 면만 채택 |
| Y 방향으로 확장한 박스 | Slab 검사 후 Y축 법선인 위·아래 바깥 면만 채택 |
| 네 모서리의 반지름 `r`인 원 | 원 교차 후 해당 모서리의 바깥 사분면에 속하는 접촉만 채택 |

core half extents가 `(hx, hy)`라면 모서리 중심은 `(±hx, ±hy)`다. 각 모서리 원 전체를 그대로 쓰면 둥근 박스 내부의 원 부분도 검사되므로, 접촉점이 그 모서리의 바깥 원호에 속하는지 부호로 확인한다.

모서리 부호를 `(sx, sy)`, 접촉점과 모서리 중심의 차이를 `q`라고 할 때 `qx × sx` 또는 `qy × sy`가 `-1e-6`보다 작으면 탈락시킨다.

현재 코드는 X 확장 박스의 유효한 면 결과를 먼저 반환하고, 다음으로 Y 확장 박스의 유효한 면 결과를 반환한다. 면에서 반환되지 않았을 때 네 원호의 유효 결과 중 가장 작은 비율을 선택한다. 모든 면과 원호 결과를 하나의 목록에 모아 정렬하는 구현은 아니다.

| 둥근 모서리 예시 | 값 |
| --- | --- |
| 대상 박스 중심 / half extents | `(0, 0)` / `(1, 1)` |
| 이동 원 중심 / 반지름 | `(2, 2)` / `0.5` |
| 요청 변위 | `(-2, -2)` |
| 접촉 원호의 중심 | `(1, 1)` |
| 최초 접촉 비율 | `(4 - √2) / 8 ≈ 0.323223` |
| 접촉 시 이동 원 중심 | `(1.353553, 1.353553)` |
| 법선 / 접촉점 | `(1/√2, 1/√2)` / `(1, 1)` |
| 접촉까지 이동 거리 | `0.914214` |

확장 AABB만 검사하면 중심 `(1.5, 1.5)`에서 접촉했다고 판단하지만, 이 위치에서 박스 모서리까지의 거리는 약 `0.707107`로 반지름 `0.5`보다 크다. 원호 검사가 이 차이를 처리한다.

## 접촉 정보와 스침 처리

| 결과 | 계산과 의미 |
| --- | --- |
| `Body` | 접촉 대상 바디 |
| `Fraction` | 이번 변위에서 최초 접촉까지의 비율. 내부 솔버에서 사용 |
| `Distance` | 요청 변위의 길이 × 접촉 비율 |
| `Normal` | 확장 형상에서 바깥으로 향하는 법선 |
| `Point` | 형상 표면의 대표 접촉점 |
| `IsGrazing` | 스침 접촉 여부. 내부 이동 판정에서 사용 |

이동 형상이 원이면 접촉 시 중심에서 `normal × radius`를 뺀 점을 사용한다. 이동 박스와 대상 원의 접촉은 대상 원의 표면점을 사용한다. 박스끼리는 법선에 해당하는 대상 면 위에서 겹치는 구간의 중앙을 사용한다. 초기 침투 결과의 Point는 이미 겹친 형상의 대표 표면점이며, 분리 후의 완전한 접촉 정보를 뜻하지 않는다.

박스는 경계 면을 따라 이동하는 경우와 진입·이탈 비율이 거의 같은 모서리 스침을 표시한다. 공개 Cast는 이런 결과도 반환할 수 있다. Sweep 솔버는 `IsGrazing` 결과와 표면 안쪽으로 향하지 않는 이동을 제외하여 이동을 불필요하게 막지 않도록 한다.
